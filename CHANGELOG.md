# Changelog

Each release's section becomes its GitHub release notes and the notes Sparkle shows in the update window, so write it for people using Otter. Add a `## [x.y.z]` section before tagging `vx.y.z`; `scripts/release.sh` refuses a version without one.

## [0.1.0]

The first release.

- Press `⌥Space` anywhere to open a floating sticky note, type, and press `⌘↩` to save. `⌘Space` works too, once Spotlight lets go of it; setup walks you through it.
- Notes are saved as Markdown files in the Otter Inbox in Documents, or any folder you choose. Inside an Obsidian vault they follow the vault's attachment and link settings.
- Paste or drop images and files to attach them.
- Bold, italic, strikethrough, code, links, bullets and checkboxes are styled as you type, and the saved file is plain Markdown.
- `⌘S` saves the note under a name you choose. `⌘1`…`⌘9` send one note to another destination.
- Save the clipboard without opening the panel, with a shortcut of your choice.
- Notes are never lost: if a folder isn't reachable, Otter keeps the note and delivers it when it can.
- Recent notes, launch at login and automatic updates.
